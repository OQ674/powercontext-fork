## 4.1 Dify DSL

| 文件 | 用途 | 导入顺序 |
| --- | --- | --- |
| `dify/grudge-tavern.dsl.yml` | 完整 Chatflow：9 个节点、8 条连线，含开场白、建议问题、角色提示词、结算代码 | 仅此一个，直接导入 |

- **适用 Dify 版本**：1.16+（DSL `version: "0.7.0"`），官方 Docker Compose 部署。
- **模型**：`deepseek-chat`（provider `langgenius/deepseek/deepseek`）。如评审环境没有 DeepSeek，把 LLM 节点换成任意已安装的 Chat 模型即可，其余节点不变。
- **需要重新绑定的地址**（导入后检查 3 个 HTTP 节点）：
  - `http://host.docker.internal:8099/v1/props/search`
  - `http://host.docker.internal:8099/v1/memory/prepare`
  - `http://host.docker.internal:8099/v1/memory/commit`
- **不需要绑定知识库**：本作品的检索走 seekdb + bridge，不使用 Dify 知识库，因此没有「知识库连接信息」需要重建。
- **变量依赖**：`sys.query`（玩家输入）、`sys.user_id`（玩家标识，用于映射 PowerContext scope）。
